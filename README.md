# BUCKG474VET6 移植与测试说明

本工程为 STM32G474VET6 Buck 控制器第一版人工调试基线。本文统一记录 LCD 移植、ADC 数据链验证、开环极性测试和单电压闭环测试，供后续开发与协作交接。整理日期：2026-10-21。

**编译入口：** 使用 Keil（ARM-MDK）打开 `MDK-ARM/BUCKG474VET6.uvprojx`，选择目标 `BUCKG474VET6` 后 Rebuild。已验证环境为 ARMCC V5.06 update 5（build 528）、Keil.STM32G4xx_DFP 1.6.0。AXF、HEX 输出在 `MDK-ARM/BUCKG474VET6/`。工程只保留 Keil 构建配置。

| 工作项 | 当前结论 |
|---|---|
| LCD 移植 | 已完成；用户已目视确认显示正常、数字清晰。扩展到 10.00 V 的显示已通过离线测试 |
| ADC 数据链 | 已按用户反馈完成验证；原始数、引脚电压和输出电压换算关系见第 2 节 |
| 开环极性 | 已完成低压两点验证，输出与反馈同向增加；保留历史实测数据见第 3 节 |
| 单电压闭环 | 软件与按键逻辑已实现，Keil 编译通过；2～10 V 全范围实物调参、动态和精度验收尚待完成 |

本文整理没有修改固件，也没有新增板上测试。历史实测与当前软件配置分别说明，不把编译通过当作硬件验收通过。

## 1. LCD 移植工作

### 1.1 移植内容与接线

参考板卡例程 `2.参考例程/6.LCD`，保留 ST7789 面板初始化、240×280 竖屏、Y 偏移 20 和 ASCII 字模，移除图片、动画及演示图形。SPI HAL 使用本项目配套的 STM32Cube G4 V1.6.3 库。

| 信号 | 引脚 |
|---|---|
| SPI1 SCK | PB3 / AF5 |
| SPI1 MOSI | PB5 / AF5 |
| LCD CS | PD11，低有效 |
| LCD DC | PD12，低为命令 |
| LCD 背光 | PD13，高有效 |

SPI 使用 8 位、模式 0、时钟八分频，当前约 21.25 MHz。主要文件为 `Core/Src/app_lcd.c`、`spi.c`、`lcd_fonts.c` 及对应头文件；LCD 接入不改变 PA0/PA1 采样、PA8 PWM、PB0 驱动使能和 PD15 按键。

### 1.2 显示与刷新逻辑

`AppLcd_Init()` 在 Buck 启动前初始化屏幕；`AppLcd_Update()` 在主循环每 50 ms 检查 `voltage_reference`，数值变化时覆盖固定数字区域。屏幕显示的是**目标电压**，不是实测输出。

- 显示两位小数，支持 `0.00 V` 和 `10.00 V`；异常值显示 `--.-- V`。
- 按键说明为 2～10 V、1 V 步进。
- 没有整屏帧缓冲或运行时延时刷新；控制和 ADC 中断仍可运行。
- SPI 发送失败时关闭背光并停止显示更新。

### 1.3 验证结果

原移植版本已完成 Keil 编译、下载和校验；验证过按键往返、长按单次、在线目标 3.25 V/0 V 及复位 2 V。旧测试记录显示 SPI 错误 0、ADC 错误 0，LCD 刷新期间 ADC 约 39944 帧/s；用户已确认字形正常。

目标上限扩展至 10 V 后，已通过 Keil 编译和 LCD 离线测试，覆盖 10.00 V、两位整数退回一位整数时的覆盖刷新、零值与异常值。扩展后的板上显示及电压响应仍需随实物测试复核。

## 2. ADC 数据链验证

### 2.1 从引脚到控制反馈

```text
TIM1 更新事件触发 ADC1
  → Rank1：PA0 / ADC1_IN1（电流）
  → Rank2：PA1 / ADC1_IN2（电压）
  → DMA1_Channel1 循环搬运两个 16 位结果
  → HAL_ADC_ConvCpltCallback()
  → BuckAdc_ConversionComplete()：取数、平滑、换算
  → BuckAdc_ReadFeedback()：复制同一帧数据供控制环读取
```

配置见 `Core/Src/adc.c`，取数和换算见 `app_adc.c`，回调入口见 `main.c`。`adc_dma_buffer[0]` 对应 PA0，`[1]` 对应 PA1；关闭 DMA 半传输中断，等两个结果均搬完再处理。

当前 TIM1 中心对齐 PWM 约 20 kHz，一个周期有两次更新事件，ADC 帧率约 40 kHz；控制环只在底部更新处理一次，控制周期为 50 μs。ADC 采样与 PI 计算频率不同。

### 2.2 关键变量与公式

| 变量 | 含义 |
|---|---|
| `adc_voltage_raw` | 当前帧电压原始计数，uint16_t |
| `adc_voltage_raw_avg` | 原始计数 EMA 平滑值，float |
| `adc_voltage_pin` | PA1 引脚电压，V；未扣零点、未乘 15 |
| `buck_voltage` | 当前帧换算的输出电压，V；单电压 PI 使用 |
| `buck_voltage_avg` | 平滑后的输出电压，V；供观察曲线使用 |
| `adc_frame_count` / `adc_error_count` | 已完成帧数 / HAL ADC 错误次数，只用于观察 |

```text
引脚电压 = adc_voltage_raw_avg × 3.3 / 4095
当前帧输出电压 = (adc_voltage_raw − 零点计数) × 3.3 / 4095 × 15
平滑输出电压 = (adc_voltage_raw_avg − 零点计数) × 3.3 / 4095 × 15
EMA：avg += 0.05 × (new − avg)，首帧直接初始化
```

电压零点保存在 `Core/Inc/adc_calibration.h`：`ADC_VOLTAGE_ZERO_RAW = 0.13525390625f`，来源为历史 4096 点采集、总和 554。其单位是 **ADC 计数**，不是 V。软件参考电压采用 3.3 V，电压前端还原倍数采用 15；这些值应由实物测量核对。

### 2.3 验证方法与现有结论

ADC 数据链已由用户验证。后续修改采样配置或硬件后，可按以下方法复查：

1. 关闭 VIN，保留正常 MCU 和采样供电。当前模式 3 复位目标为 2 V，连接后将 `voltage_reference` 写为 0 并读回，保持停止输出；此时不按调压键。
2. 万用表分别测 VOUT 对输出地、SAMPLE_V 对 MCU 地，记录直流值。
3. 对照 `adc_voltage_raw_avg`、`adc_voltage_pin`，检查帧数持续增加、错误数为 0。
4. 手算 `预计计数 = SAMPLE_V(V) / 3.3 × 4095`，与软件比较；正电压响应再结合第 3 节核对。

例如 SAMPLE_V=32.2 mV，应先换算为 0.0322 V，预计约 39.96 个计数。零附近相符只能说明该点读数合理，帧数增加或错误数为 0 也不能单独证明全量程精度。若原始数卡住、贴近 4095 或与引脚测量明显不符，先查通道、参考、地和 AXF 符号地址。

## 3. 开环极性测试

### 3.1 目的与历史测试条件

验证方向为：**占空比增加 → VOUT 增加 → SAMPLE_V 增加 → ADC 计数和软件反馈增加**。历史测试采用 12 V 输入、约 2.5 Ω 负载，以 5% 和 10% 两个低压点核对方向及前端比例。

测试模式在 `Core/Src/app_control.c` 中选择：

```c
#define BUCK_CONTROL_MODE 2U
/* 在 BuckControl_ParameterInit() 中，两个测试点分别使用： */
openloop_command = 0.05f * arr;  /* 5% */
/* 或 openloop_command = 0.10f * arr;  10% */
```

**当前源码的模式为 3，开环初始化值为 `0.3f * arr`（30%）**。它与上述历史测试条件不同；重新做两点测试时，需要明确改成对应值，不能只把模式切到 2 就认为是 5%。本文没有改动这些源码参数。

### 3.2 测试步骤

1. 关闭 VIN，再修改模式与占空比；用 Keil 编译、下载并运行。模式 2 下，给定正 `openloop_command` 会产生 PWM。
2. 先测 5% 点，记录板端 VIN、VOUT、SAMPLE_V、原始均值、`buck_voltage_avg` 及输入电源 CV/CC 状态；关闭 VIN 后核对回到基线。
3. VIN 关闭时改为 10%，重新编译下载，在相同负载下记录第二点。
4. 比较方向与增量比例。输入电源处于持续限流降压时，先处理供电条件，再比较两个点。

历史两点低压测试使用过 0.2 A 输入限流；该设置不能沿用来判断高输出电压下的带载能力。模式 2 的停止命令是 `openloop_command=0`，`voltage_reference=0`不控制开环停止。

### 3.3 历史实测结果

| 开环占空比 | VOUT 实测 | SAMPLE_V 实测 |
|---|---|---|
| 5% | 0.5002 V | 32.2 mV |
| 10% | 1.035 V | 68.2 mV |

```text
前端缩小倍数 ≈ (1.035 − 0.5002) / (0.0682 − 0.0322) ≈ 14.86
```

两点实测证明低压范围内 VOUT 与采样信号同向增加，前端比例与代码中的 15 倍接近。该结论支持后续使用负反馈闭环，不等同于全量程精度标定。历史材料没有提供这两点完整的 ADC 原始均值记录，本文不补造数据。

## 4. 单电压闭环测试

### 4.1 当前软件配置

```text
voltage_reference − buck_voltage
  → 独立单电压 PI（voltage_only_pi）
  → PWM 比较值
  → Buck 输出
  → 电压采样反馈
```

| 项目 | 当前值或行为 |
|---|---|
| 模式 | `BUCK_CONTROL_MODE=3U` |
| 复位目标 | 2 V，采样有效且检查通过后会尝试闭环输出 |
| 正常目标范围 | 2～10 V |
| 按键 | PD15，按下/松开消抖 20 ms；长按单次；2→3→…→10→9→…→2 V |
| 步进 | 1 V，换档不清积分 |
| 单电压 PI 初值 | Kp=1、Ki=2、Kd=0，尚需实物整定 |
| PWM 周期 / ARR | 约 50 μs / 4249，比较值上限取当前 ARR |
| 人工停机 | 写 `voltage_reference=0`，控制中断关闭驱动与 PWM 主输出并清积分 |

Kp 单位为占空比百分点/V，Ki 为百分点/(V·s)。`pid.c` 内部已换算 ARR 并乘控制周期，不需人为再乘。`voltage_only_pi.Out` 和 `buck_duty` 是 PWM 比较计数，占空比约为 `Out / ARR × 100%`。

正常目标范围之外的正给定停止输出。停机后按一次按键会恢复 2 V；复位也恢复源码中的 2 V 和 PI 初值。当前目标上限只是参数检查，软件没有按输出电压阈值关断的 OVP；模式 3 不使用电流通路作过流保护，仍有 ADC 电压原始值饱和、ADC 错误及参数有效性检查。

### 4.2 工具与操作顺序

- **MCUViewer：** 新建工程，选择原生 STLINK，加载与板内固件配套的 `MDK-ARM/BUCKG474VET6/BUCKG474VET6.axf`。Table 添加目标、Kp、Ki；Curve 观察 `voltage_reference`、`buck_voltage_avg`、`voltage_only_pi.Out`。不需要旧桥接脚本；与 Keil Debug 轮流使用 ST-Link。
- **万用表：** 测 VOUT，作为稳态电压依据；LCD 仅显示目标。
- **示波器：** 观察启动、1 V 升降阶跃及纹波。MCUViewer 的低速平滑曲线不能代替动态波形。

修改源码、烧录或切换模式前关闭 VIN；Keil 编译下载后运行并退出 Debug，再连接 MCUViewer。当前复位后目标为 2 V，不再采用旧文档中“默认 0 V、从 0.5 V 起调”的流程。停止采集或断开 ST-Link不等于停止功率输出。

### 4.3 调参与验收

1. 在 2 V、固定负载下建立实测基线；先令 Ki=0，从较小 Kp 开始比较响应。代码在 Ki=0 时会清积分，切换会引起输出变化。
2. 保持合适的 Kp，从较小 Ki 逐步增加以消除静差。一次只改一个参数，等待读数和波形稳定；出现过冲或振荡时回退并记录。
3. 按 1 V 逐档上升至 10 V，再逐档下降至 2 V。记录实际输出、稳态波动、阶跃过冲和稳定时间，复查约定的负载条件。
4. PWM 长时间到上限、输入限流或反馈与万用表不符时，先排查供电、负载和采样，不继续增加 Ki。
5. 确定 PI 后写回源码，重新 Keil 编译、下载；MCUViewer 写入 RAM 不会永久保存参数。

沿用旧文档的暂定验收口径：`稳态相对误差 = |万用表实测 − 目标| / 目标 × 100% ≤ 20%`；若正式需求另有规定，以正式需求为准。每档可连续观察 10 秒，记录最小和最大值并取最坏误差。1 V 步进是设置分辨率，不是输出精度。
