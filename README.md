## 1. 当前接线

“排针第几脚”指功率板上编号U1的2×4采样排针，以原理图脚号为准。

| 功率板排针/信号 | MCU最小系统板 | 用途 |
|---|---|---|
| 第1脚 SAMPLE_VBAT | PA1 / ADC1_IN2 | 电池端口电压，名义电压/15 |
| 第3脚 SAMPLE_VBUS | PC1 / ADC1_IN7 | 母线电压，名义电压/15 |
| 第5脚 SAMPLE_I | PA0 / ADC1_IN1 | 电池支路电流，正充电、负放电 |
| **第7脚 REF** | **PC0 / ADC1_IN6** | INA213参考电压，名义约1.6667V，必须实际接线 |
| 第2/4/6/8脚 GND | MCU GND | 测控公共地，不接IBAT来旁路分流器 |
| PWM_IN | PA8 / TIM1_CH1 | 单路PWM，IR2104内部产生互补和死区 |
| PWM_EN / SD# | PB0 | 高允许运行，低使上下管均关断 |

LCD：PB3/PB5为SPI1时钟/数据，PD11/PD12/PD13为CS/DC/背光；按键PD15；USART2沿用PA2/PA3。
LCD SPI为8位数据。旧蓝牙业务和旧PID模块不参与本工程，已清理；USART2基础配置保留。

## 2. 硬件与采样状态

最终连接核查见[当前硬件说明](../仿真/硬件核查/当前硬件说明.md)。
采样输出已与VBAT/VBUS功率网分开，阻值料号、逐片100nF去耦、两路参考跟随器均已核对。
GND/AGND经0Ω相连，R4测电池支路电流。正常量程沿用5V模拟供电，无额外2k/3k输出分压。
异常过压与掉电时序保护仍是原型限制，不将连接核查当成已完成全故障保护。

TIM1：170MHz、中心对齐、ARR=4249，PWM约20.0047kHz。
每个峰/谷触发四路ADC，约40.0094k帧/s；ADC时钟42.5MHz，每路47.5周期采样，
整帧约5.65µs，小于25µs触发间隔。扫描为电流→REF→电池电压→母线电压，电流/REF相邻；
控制仍每个PWM周期运行一次。CubeMX的IOC与实际生成代码一致，重新生成时保留USER CODE。

## 3. 人工调参只用两个头文件

| 文件 | 作用 |
|---|---|
| `Core/Inc/adc_calibration.h` | ADC实际参考电压、电流残余零偏/增益、两路电压零点/比例 |
| `Core/Inc/control_settings.h` | 四个PI默认值、参考变化速度、保护阈值 |

电流：`I=(raw[0]-raw[3]-ADC_CURRENT_OFFSET_RAW)*ADC_REFERENCE_VOLTAGE/4095*ADC_CURRENT_A_PER_PIN_V`。
raw[0]是电流，raw[3]是实时REF；OFFSET是相减后仍存在的零电流残差，名义0。
增益名义2.017A/V已计入两只10Ω输入电阻；实物须两点标定。电压名义比例均为15。
不再固定减去2068码，也不使用0.6倍或25倍换算。

观察数组：`adc_feedback.raw[0]`电流、`raw[1]`电池电压、`raw[2]`母线电压、`raw[3]`REF。
`adc_feedback.reference_voltage`为REF实测电压。REF码不在1500～2800、ADC饱和、DMA错误
或采样停更时，运行请求会触发故障5。

## 4. 操作与控制

- 上电STOPPED，只采样和显示。停机短按切CC/CV/AUTO，长按约0.8秒启停。
- CC运行时短按按0.1A在1～2A间折返调整；CV/AUTO运行时短按不切模式。
- 人工变量：`output_enable`、`control_mode`、`charge_current_set`、`bus_voltage_set`和`control_gains`四个成员。
- PI默认值：电流Kp=0.020、Ki=8；电压Kp=10、Ki=120。人工填写按秒定义的Ki，内核积分时再乘控制周期。
- 先实物标定，再CC电流环，再CV电压外环，最后AUTO。无需操作内部积分和斜坡状态。
- 故障码：1电池过压/过充，2欠压，3电池支路过流，4母线过压，5采样故障，6参数非法，7CPU异常。
  先停机查原因，不直接写0绕过故障。
- SD#低才关断驱动；PWM关闭不能隔断体二极管通路。首次接入考虑预充。
  软件±2.8A是电池支路阈值，不是电感峰值保护。

## 5. 仿真和构建

算法源文件为 `../仿真/程序/dcdc_step.m`，生成C在 `Core/Generated`，日常调参不手改生成C。
本轮AUTO2加入参考变化前馈（有效235µH）和电流反馈超前150µs，参考斜率40000A/s。
模型按PWM1谷值高电平、两次ADC逐路采样、谷值控制和峰值CCR装载运行，保留R4支路电流与电池侧电容。
32↔38V突变按三个相位验证；标称通过范围与容差超限角见`结果/AUTO2_突变验收.json`，不能保证未实测硬件全部通过。

MATLAB在“仿真”目录执行 `run_all`：回归所选方案、测量比较、实际Coder生成、
20,000步原生C一致性验证，通过后同步C/H。脚本不烧录。
Python `../仿真/程序/verify_ref_adc.py`验证实际ADC源码四路顺序、正负电流与REF扣除。
